# Example Build Helpers

Not an example. A thin re-export of `build_lib/zaza_cmd.zig` for example build files.

## What it demonstrates

- Zig 0.15 removed `usingnamespace`, so the public declarations are forwarded explicitly.

## Prerequisites

Zig 0.14.1 or 0.15.2. Nothing else.

## Build and run

There is nothing to build here. The module is imported by other example build files.
